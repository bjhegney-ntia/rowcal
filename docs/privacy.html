Rowcal Privacy Policy

Last updated: November 9, 2026

Rowcal is a Google Sheets add-on that turns spreadsheet rows into Google Calendar events and imports calendar events into a sheet. It is built so that your data stays inside your Google account.

What Rowcal accesses

  • The spreadsheet it is open in (scope: spreadsheets.currentonly). Rowcal reads the rows you choose to sync and writes a hidden "Rowcal ID" column so it can update events instead of duplicating them. It cannot see your other spreadsheets.
  • Calendar events (scope: calendar.events). Rowcal creates, updates and deletes events on the calendar you pick, only when you press Sync or turn on auto-sync. It never shares calendars or changes calendar settings.
  • Your list of calendars (scope: calendar.calendarlist.readonly), so you can pick one from a menu and so Rowcal knows that calendar's time zone.

What Rowcal stores

Settings (which calendar, which columns), a list of event IDs it created, and a run log are stored inside the spreadsheet's own properties and a hidden "Rowcal Log" sheet. A monthly usage count and, if you upgrade, the email you used at checkout are stored in your Google account's add-on properties. Nothing is stored on servers run by Rowcal.

What leaves Google

Only one thing: if you activate Rowcal Pro, the add-on asks Stripe whether the checkout email you typed has an active subscription. No spreadsheet or calendar content is ever sent anywhere. Payments are handled entirely by Stripe under Stripe's privacy policy.

Google API Services User Data Policy

Rowcal's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data is used only to provide the sync and import features you ask for. It is not used for advertising, not sold, and not shared with anyone.

Removing Rowcal

Uninstall the add-on from Google Sheets or revoke access at myaccount.google.com/permissions. Delete the hidden "Rowcal ID" column and "Rowcal Log" sheet if you no longer want them. Events already on your calendar stay there.
