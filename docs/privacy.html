Minutehand Privacy Policy

Last updated: November 10, 2026

Minutehand is a Google Sheets add-on that turns spreadsheet rows into Google Calendar events and imports calendar events into a sheet. It is built so that your data stays inside your Google account.

What Minutehand accesses

  • The spreadsheet it is open in (scope: spreadsheets.currentonly). Minutehand reads the rows you choose to sync and writes a hidden "Minutehand ID" column so it can update events instead of duplicating them. It cannot see your other spreadsheets.
  • Calendar events (scope: calendar.events). Minutehand creates, updates and deletes events on the calendar you pick, only when you press Sync or turn on auto-sync. It never shares calendars or changes calendar settings.
  • Your list of calendars (scope: calendar.calendarlist.readonly), so you can pick one from a menu and so Minutehand knows that calendar's time zone.

When you install from the Google Workspace Marketplace, Google also shows two standard permissions that it adds to every Marketplace app: seeing your email address and your basic profile. Minutehand does not read, use or store either.

What Minutehand stores

Settings (which calendar, which columns), a list of event IDs it created, and a run log are stored inside the spreadsheet's own properties and a hidden "Minutehand Log" sheet. A monthly usage count and, if you upgrade, the email you used at checkout are stored in your Google account's add-on properties. Nothing is stored on servers run by Minutehand.

What leaves Google

Only one thing: if you activate Minutehand Pro, the add-on asks Stripe whether the checkout email you typed has a completed purchase. No spreadsheet or calendar content is ever sent anywhere. Payments are handled entirely by Stripe under Stripe's privacy policy.

Google API Services User Data Policy

Minutehand's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data is used only to provide the sync and import features you ask for. It is not used for advertising, not sold, and not shared with anyone.

Removing Minutehand

Uninstall the add-on from Google Sheets or revoke access at myaccount.google.com/permissions. Delete the hidden "Minutehand ID" column and "Minutehand Log" sheet if you no longer want them. Events already on your calendar stay there.
